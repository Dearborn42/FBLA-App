# Student Profile App

This is a mobile application built using the MERN stack approach with React Native and Expo. The purpose of this app is to allow students to create profiles that encompass various aspects of their high school experience, including grades, elective courses, jobs, and community service activities.

## Features

- **User Authentication**: Secure user authentication system to ensure privacy and data protection.
- **Profile Creation**: Allows students to create detailed profiles containing information about their academic achievements, elective courses taken, work experiences, and community service activities.
- **Grade Tracking**: Provides a platform for students to input and track their high school grades over time.
- **Elective Courses**: Enables students to list the elective courses they have taken during their high school years.
- **Work Experience**: Allows students to document their job experiences, internships, or part-time work.
- **Community Service**: Provides a section for students to log their participation in community service activities or volunteer work.

## Technologies Used

- **React Native**: A JavaScript framework for building mobile applications.
- **Expo**: A platform and set of tools for building and deploying React Native applications.
- **MongoDB**: A NoSQL database used to store user profiles and related data.
- **Express.js**: A web application framework for Node.js used to create RESTful APIs.
- **Node.js**: A JavaScript runtime used to run server-side code for the application.


## Usage

- Sign up or log in to create your student profile.
- Fill out the various sections of your profile, including grades, elective courses, work experience, and community service activities.
- Update your profile as needed to reflect changes in your academic or extracurricular activities.
- View and edit your profile at any time to keep it up to date.
